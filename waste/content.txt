# 8. Global Interactive Features
- **Animations**:
  - Scroll-triggered fade-in animations on all sections
  - Floating 3D background element (rotates on scroll)
  - Card hover effects (lift, border glow)
  - Button hover states (scale, opacity changes)
  - Tag hover effects (border color change)
- **Responsive Design**:
  - Mobile menu toggle
  - Grid layouts adapt: 2-column on desktop, 1-column on mobile
  - Text sizes scale down on smaller screens
- **Accessibility**:
  - All buttons have aria-labels
  - Keyboard navigation support
  - Focus states on interactive elements
